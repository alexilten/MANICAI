## Tools in the landscape

- **HOK Scrum:** HOK's proprietary Grasshopper/Rhino seating-bowl tool (lead developer Carlos DelaBarrera). Public description: real-time 3D bowl, seat width, sightlines, proximity, rake, row elevation, concessions/restroom access, acoustics, event-specific scoring, seat-level revenue modelling, precast-length rationalisation (Roig Arena); integration with HOK STREAM for steel tonnage described as in progress. A bowl can be set up in a day; 2–3× faster. MANICAI has no access to its code or methods. ([source](https://www.hok.com/ideas/research/hoks-scrum-a-game-changing-design-tool-for-sports-and-entertainment-venues/), checked 2026-10-25)
- **Rhino + Grasshopper (custom definitions):** The de-facto professional environment for parametric bowls; powerful but expert-only. MANICAI exports native .3dm so work continues there. ([source](https://www.rhino3d.com/), checked 2026-10-25)
