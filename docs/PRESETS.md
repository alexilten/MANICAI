# Presets

_Generated by `npm run docs` from the MANICAI source data. Do not edit by hand._

Presets are starting points. **Generic** presets use MANICAI planning defaults. **Precedent-informed studies** are independent parametric bowls built from a few published facts about a real project: capacity, sport, tier count and roof type. The engine fits the row counts to the published capacity.

They are **not** the architects' geometry, they use no drawings or CAD, and they are not affiliated with or endorsed by MANICA, Populous, HOK or any studio named. Confidence is **low** for all precedent presets because only the capacity and a qualitative bowl description are published.
