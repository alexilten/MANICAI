# Standards and assumptions registry

_Generated by `npm run docs` from the MANICAI source data. Do not edit by hand._

Every rule MANICAI applies or reports, with its kind and how it was verified.

- **governing**: a rule of the sport or a code requirement.
- **guidance**: published design guidance (FIFA, SGSA Green Guide).
- **assumption**: a MANICAI planning default. You can change it in the project.
- **engineer-review**: outside what the tool can decide. A qualified professional must check it.

Verification: **checked** means the rule was read in the cited source on the date shown. **recall** means it is reference knowledge that was not re-read this round, and it must be checked before you rely on it. Standards change and vary by jurisdiction. MANICAI is a planning tool, not a code-compliance tool.
